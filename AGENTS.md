# Agent instructions

All coding agents (Claude Code, Codex, Cursor, Copilot and others) follow the same rules in this
repository. They live in `CLAUDE.md` files so there is one copy:

1. Read `CLAUDE.md` in this folder first.
2. Then read the `CLAUDE.md` closest to the files you will change:
   `src/CLAUDE.md`, `supabase/CLAUDE.md`, `supabase/functions/_shared/followups/CLAUDE.md`,
   `extension/CLAUDE.md`.
3. Plan first and wait for approval before writing code. The workflow is in `CLAUDE.md`,
   section "How work gets done here".
