# 🚀 TrackMate UI  
A modern, intuitive job application tracking dashboard inspired by TealHQ — rebuilt from scratch with a clean and scalable architecture.

TrackMate UI helps users manage their job search, organize applications, track progress, and store important documents — all in one place.

---

## ✨ Features

### **Dashboard Overview**
- Centralized view of job activity  
- Summary of active applications, saved jobs, tasks, and priorities  
- Clean and fast navigation experience  

### **Job Application Tracker**
- Add, update, and organize job applications  
- Pipeline workflow: **Saved → Applied → Interviewing → Offer → Closed**  
- Notes, tags, and priority levels for each entry  
- Visual progress tracking  

### **Task & Reminder System**
- Create and manage job-related tasks  
- Track follow-ups, interviews, and next steps  
- Simple reminder-style workflow  

### **Document Manager**
- Manage resumes, cover letters, and templates  
- Quick-access layout for frequently used files  
- Structured and clutter-free document space  

### **AI-Ready Components**
- Architecture prepared for AI integrations  
- Potential for resume suggestions, job scoring, and auto-messages  
- Flexible foundation for future ML modules  

### **Responsive Design**
- Fully responsive across desktop, tablet, and mobile  
- Smooth adaptive layout  
- Lightweight and fast UI  

### **Modular Architecture**
- Reusable components  
- Clean folder structure  
- Simple to extend and integrate with backend services  

---

## 🏗️ Tech Stack
- **Framework:** React / Next.js  
- **Styling:** TailwindCSS / CSS Modules / shadcn/ui  
- **State Management:** Zustand / Redux Toolkit  
- **Routing:** React Router / Next.js Router  
- **Animations:** Framer Motion  
- **Build Tools:** Vite / Webpack  
- **API Layer:** Axios / Fetch
