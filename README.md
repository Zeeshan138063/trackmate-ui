# 🎯 CareerPilot AI - AI-Powered Career Growth & Job Tracker

CareerPilot AI is the ultimate AI-powered career assistant. Track job applications, manage your professional network, and build AI-tailored resumes with ease.

## ✨ Features

- **Dashboard**: Get a high-level overview of your career activity.
- **Application Tracker**: Manage your job hunt pipeline effectively.
- **Resume Builder**: Create and tailor resumes for specific job descriptions using AI.
- **Connections Hub**: Organize your professional network and track follow-ups.
- **AI Copilot**: Get intelligent insights and assistance throughout your career journey.

## 🏗️ Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`

## 🧩 Browser Extension

The CareerPilot AI Job Capture extension allows you to save jobs directly from LinkedIn, Indeed, and other platforms.
