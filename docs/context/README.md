# Context drops

A context drop is a dated document that brings a fresh session up to speed on a piece of work: what
was found, what was decided, what is next, and the traps that cost time. Name it
`YYYY-MM-DD-<topic>.md` and link it from the module handoff.

Write one at the end of any session that learned something the code does not show. List the newest
at the top of this file, with one line saying what it is and whether it supersedes an older drop.

- `2026-11-26-agent-setup-and-architecture.md`: first architecture read, agent setup, and the traps found. Supersedes nothing.
