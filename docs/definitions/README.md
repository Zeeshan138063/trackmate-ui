# Definitions

Business terms written down **once**, by whoever owns them, and answered by **one** server function.

If two screens compute "days overdue" separately, they will disagree within a month. So each term
here names the single function that computes it, and every screen, report and export reads that
field instead of working it out again.

Copy `_TEMPLATE.md`. The owner's words go in verbatim; engineering may not reinterpret them.
